## Pro、Eyeball、Tier 1 三档线路差在哪

DMIT 每个机房都分三档卖，配置接近，价差全在线路上。

Pro 的三网回程都是 CN2 GIA，电信联通去程也走 CN2 GIA，移动去程走 CMI。贵的一部分买的是承诺：官方在合同层面写明，即便遭遇攻击或成本上涨，也不会把 Pro 降级到低线路。市面上便宜的 CN2 机在特殊时期切路由的情况不少见，Pro 卖的就是这个不切换路由的保证。

Eyeball（EB）回程换成 CMIN2，电信联通去程走 CN2/9929，价格低一档。联通、移动用户用起来比较突出，电信用户的感知差距会比 Pro 明显一些。

Tier 1（T1）是国际优化线路，没有大陆专项优化，价格最低，流量超了不停机，只切限速。访客主要在海外的话，T1 就够用，Pro 多花的钱买不到对应收益。

香港和东京的 Pro 同样是三网优化，回程走 CN2 GIA 这一档，去程的具体路由在公开整理里存在两种说法：一种说和洛杉矶一样全程 CN2 GIA，另一种说电信 CN2 GIA、联通 AS9929、移动 CMI 分线路走。两种说法都指向“三网各自优化”，但细节对不上，买之前看一眼官网产品页的路由说明更稳。

## 洛杉矶、香港、东京怎么选

延迟差是唯一需要算清楚的数字。公开测评里，洛杉矶到国内三网大致 150–165ms，晚高峰和清晨差异小、丢包控制得不错；另一份测评给的范围宽一些，150–200ms。香港到国内通常落在 20–50ms。

100ms 以上的差距值不值那个溢价，看用途：

- 网页访客为主。首次加载多 100ms，主观感受不明显，洛杉矶的性价比更高，同样的钱能拿到更大的带宽口子和更多流量。
- SSH 交互、远程桌面、实时通信、游戏加速这类场景。香港 20–50ms 的体验和洛杉矶 150ms 不是一个量级，年付 $259.9 起的价格里有一半买的是这个手感。
- 需要日本 IP 或面对日本、亚太市场。东京 Pro 月付 $21.9 起，价格夹在两者中间，地理位置是主要理由。

顺带说一个容易被忽略的点：洛杉矶 Pro 的带宽口子比香港宽。香港全系 500Mbps，洛杉矶常规款 1Gbps 起。跑大流量下载或者做镜像站，这个差别比延迟更影响体验。

## 一年到底花多少：年付限量款和月付常规款的价差

这是选 DMIT 时最该算清楚的一笔账，因为同一档线路，年付限量款和月付常规款的价格差了 2–3 倍。

洛杉矶的年限量款：WEE $36.9/年，MALIBU $49.9/年。它们是年付制，没有月付选项，配置也更低（1核1G）。折成月均分别是 $3.08 和 $4.16。

洛杉矶月付常规款：AN5 平台 TINY $9.99/月，一年 $119.88；POCKET $14.90/月，一年 $178.80；STARTER $29.90/月，一年 $358.80；MINI $58.88/月，一年 $706.56。

拿 WEE 和 TINY 比：一年 $36.9 对 $119.88，差 3.2 倍，代价是内存 1GB 对 2GB、硬盘 10GB 对 20GB。拿 MALIBU 和 POCKET 比：$49.9 对 $178.80，差 3.6 倍，配置同样是低一档。也就是说，能接受 1核1G、能等补货，就省掉三分之二的钱。

香港和东京没有这种低价年付特供，价格曲线平得多：HKG.Pro.TsuenWan $259.9/年，TYO.Pro $21.9/月起算，一年 $262.8 起。想要低成本入口，只有洛杉矶的限量款这一条路。

关于折扣，说清楚三个机制就够了。DMIT 的促销码多数是循环折扣，续费按同一折扣价走，不是首年便宜续费涨那种；每单只能用一张码，不能叠加；大部分码只对季付或年付生效，月付享受不到。至于当前哪个码还能用，只能自己粘进购物车的 Apply Promo Code 里点 Validate Code 看折扣是否真的到账，网上流传的码时效性很差，过期了不会有人通知你。

## 几条容易踩坑的规则

这些条款不在购买页显眼位置，但每一条都会影响你用起来顺不顺。

**新账号有 7 天等待期。** 注册完不能马上下单，急着买的要提前几天注册好账号，别等到补货那天现注册。

**默认 SSH 密钥登录，不是密码。** 拿到机器第一件事是去控制台 Access 页面下载密钥包，里面包含 PuTTY 用的 `.ppk` 文件。不习惯密钥登录，可以重装系统改成密码，步骤稍多但可行。

**退款窗口是 3 天内、流量不超过 30GB。** 在这个范围内可以申请全额退款，不确定自己网络环境适不适合的，先买最小套餐跑几天测试线路，不合适就退。超过这个窗口之后的处理方式，公开说法有出入（一种说只退到账户余额、无手续费，另一种说按剩余价值退并扣支付手续费），真要用到这条，以官网条款原文为准。

**换 IP 每 15 天一次免费。** 洛杉矶 Pro 和 EB 系列，IP 被墙可以自助免费更换，2026 年 1 月起改成控制台自助操作，不用开工单等客服。其他机房或其他情况 $5/次。

**流量超量不停机。** T1 系列超量后切限速模式，下个月流量重置后恢复；洛杉矶 Pro 超量限速到 2Mbps，仍能访问但速度很慢。跑数据密集任务时不用一直盯着流量表。

**默认给 1 个 IPv4 加 1 个 /64 IPv6**，IPv6 走 CMIN2 线路。

**限量款补货窗口很短。** MALIBU、WEE、PalmSpring 这类，补货后常在几小时内售罄，黑五、双十一、圣诞元旦前后补货频率会高一些。

## 什么情况下 Pro 是过度配置

DMIT 的 Pro 档不便宜，把它推荐给所有人是浪费别人的钱。下面这几种情况，多花的钱基本打水漂。

访客主要在海外，或者做的是面向欧美的独立站，T1 系列完全够用，价格低一大截，国际路由本来就不差。

预算卡得很死、又不做大陆优化刚需的业务，EB 系列是更合理的选择，CMIN2 对联通移动用户足够友好，价格比 Pro 低一个档次。

只在上面学 Linux、跑点脚本练手，最便宜的入门款就行，线路质量对你的使用场景没有影响。

还有一种：对延迟极度敏感但又只愿意付洛杉矶的价格。这种需求本身矛盾，香港 Pro 的低延迟是用钱换的，没有便宜的替代方案，硬上洛杉矶再抱怨延迟没意义。
